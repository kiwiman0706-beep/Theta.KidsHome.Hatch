# くるくる思考パッド（kids.edupad）

小学校受験・幼児向けの**空間認識／回転推理**を、タブレット上で指やペンで「ぐりぐり」動かして実感するための**Sandbox（自由操作）アプリ**（PWA）。正誤判定のクイズではなく、**触って動かして「そうなるのか」と分かる**ことに振り切っています。記号・分割数・形を差し替えて自由に作り替えられ、授業・家庭学習の両方で使えます。

- 対応端末：Androidタブレット（iPlay60 Pro など）＋スタイラスペン。Pointer Events でペン・指・マウスすべてに対応。
- 依存ライブラリなし。`app/index.html` 単体で動作（オフライン可）。

すべて**自由操作（Sandbox）**です。正誤を採点するクイズはありません（「動かした結果」が見えるだけ）。右上「⚙️ せってい」で**記号・数・形を差し替え**て自由に作り替えられます（端末に自動保存）。

- **📷 ほぞん**（ヘッダー）：今の画面をPNGでキャプチャ→Androidは共有シートからフォト（カメラロール）へ、他はダウンロード。

## 使い方

### いちばん簡単：ファイルを開く
`app/` フォルダ一式を端末に置き、`app/index.html` をブラウザで開くだけ。オフラインで動きます。

### おすすめ：GitHub Pages で配信（URLで全員が使える・PWA化）
1. GitHub でこのリポジトリを **Public（公開）** にする。
   → 公開なら Pages が**無料**。以後は「push するだけ」でURLが自動更新され、更新の手間が激減します（非公開は Pages が有料プラン必要）。
2. リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main`（フォルダは `/root`）に設定。
3. 数十秒後に `https://<ユーザー名>.github.io/kids.edupad/` が公開されます。
   （ルートの `index.html` が `app/` へ自動転送します。）
4. タブレットでそのURLを開き、ブラウザメニューの **「ホーム画面に追加」** →
   全画面アプリ（PWA）として起動、**オフライン動作**します。

> PWA更新：アプリを直したら `app/sw.js` の `CACHE = 'kuru-vN'` の番号を1つ上げると、
> 各端末が次回起動時に新版を取り込みます。

## 類題の作り方（先生向け）
- 各モジュールの「⚙️ せってい」で、絵文字・数字・文字、分割数、盤面の記号、積み木の形などを差し替え。
- 回転盤は「設定コピー／貼り付け」で他の先生と共有可能。
- 設定は各端末の localStorage に自動保存。

## 技術メモ
- Canvas 2D ＋ Pointer Events（`pointerType:'pen'` でペン対応、`touch-action:none` でスクロール抑止）。
- 単一HTMLに共通エンジン＋モジュールを実装。モジュールは `make()` で生成し、共通ルーターがポインタを委譲。
- PWA：`manifest.json` ＋ `sw.js`（app-shell キャッシュ、HTMLはネット優先で更新反映）。
- 将来 Google Play 用の APK 化が必要になれば、この Web アプリを Capacitor / TWA でラップして配布できます。
