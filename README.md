## できること

- **画面の右はしのタブ**
  - 🏠 ホーム：アプリ・おえかき・でんわのボタン、マスコット、カレンダー（つき／しゅう、端末の予定つき）、おんがくの ⏮ ⏯ ⏭
  - 📼 ビデオ・🎵 おんがく・🎧 おはなし：本体と SD カードの動画・音楽・オーディオブックを、サムネイルで選んでホームの中で再生
  - 🗂 仕分けたカテゴリー（べんきょう・あそび…）：その子に見せるカテゴリーだけ
  - 🕐 とけい：アナログ時計（ごぜん／ごご・ふん の数字つき）、カレンダー、てんき（Open-Meteo）、でんち
  - 🎬 動画サービスごと（Netflix・Prime Video・YouTube…）：ピン留めした作品と「アプリをひらく」
  - 🧩 ウィジェット：Android のウィジェットを置ける（置いたときだけ出る）
- **📞 でんわボタン**：Google Meet などの通話リンクを置ける（どうがロック中も使える）
- **📣 おうちのひとからの呼びかけ**：スマホのブラウザから「そろそろ おわりだよ」を送ると、動画を見ていてもキッズホームが前に出てマスコットが知らせる。`/lock 30 ごはんだよ` でロックも
- **キャラクターテーマ**：うさぎ / ねこ / くま / きょうりゅう / ユニコーン / うみ / おほしさま
- **こどもごとのホーム**：画面右上のアイコンをタップで切り替え（最大4人）
- **お気に入り動画を直接起動**：Netflix・Prime Video・YouTube・Disney+・TVer などの作品URLをボタンにできる
- **アプリの登録**：くるくる学習パッドなど、使わせたいアプリだけを並べる
- **がっき**（内蔵）：上に ミニけんばん（2 オクターブ、ドレミの色つき）、下に ドラムパッド 8 こ。けんばんは ピアノ／オルゴール／オルガン／もっきん／シンセ、ドラムは ドラム／でんし／たのしい に切り替え。いくつ同時に押しても、指をすべらせても鳴る（音はアプリの中で計算して作る）
- **おえかき**（内蔵）：画材（ペン・いろえんぴつ・クレヨン・すいさい・あぶらえ・スプレー・ゆび・にじ・けしごむ）とスタンプ。描いたものは自動で保存して 📂 から開いて つづきを描ける。🖼️ 写真の上に描く、✨ 写真を Gemini で ぬりえ・クレヨン・すいさい・まんが の絵にしてから描く。🖊️ ペンモード（スタイラスだけで描く・手のひらは無視・筆圧・ペンのおしりで消す）、🖨️ 印刷、💾 写真に保存、📌 ホームに ふせん として貼る
- **わーぷろ**（内蔵）：大きな文字、色・大きさ・紙（むじ・せん・ます）・ドット字、えもじ、🎤 こえ入力、📌 ふせん、🖨️ 印刷、自動保存
- **パズル**（内蔵）：写真・えほんの絵をピースにして はめる（4〜24 ピース、🔄 回転あり、👻 見本の表示）
- **タイピング**（内蔵）：物理キーボードでローマ字入力の練習（特打のように、つぎのキーが光り、押す指を色で教える）。📖 ローマじ ひょう、ホームポジション・あいうえお・どうぶつ・たべもの・のりもの・みじかい ぶん
- **もじ れんしゅう**（内蔵）：マスに ペンで書く（お手本は よこに小さく・田の点線・筆圧・ペンモード）。書いた字は 1 字ずつ保存され、いつのまにか その子の **手書きフォントの素材** が集まる。学年に合わせて漢字が増える（4 月に自動で 1 つ上がる）
- **ふせん**：おえかき・わーぷろ から ホームに貼れる。指で動かす、タップで大きく・はがす
- **どうがロック**：15分〜2時間 / あしたの朝まで。「べんきょうタイム」「ごはんタイム」などの理由を表示
- **おうちのひとメニュー**：⚙️ を **2秒ながおし** → **かけ算**に答える（2けた×1けた、設定で 2けた×2けた）
  - 「📱 すべてのアプリ」：端末のアプリをぜんぶ表示・起動
  - 「⚙️ せってい」：ボタンの登録、どうがロック、アップデート、レスキュー
- **あそび**：マスコットをタップ → ジャンプ・くるりん・おしゃべり／背景をタップ → キラキラ／ときどき歩いてくる いきものをつかまえると ほし⭐
- **自動更新**：1時間に1回まで GitHub Releases を確かめ、新しい版があれば ⚙️ に赤い点。せってい →「アップデートする」
- **レスキュー**：落ちる・固まるのが続くと、自動でレスキュー画面（別のホームを選ぶ／セーフモード／最新版）。通知パネルのクイック設定のタイルからも開ける（開くときもかけ算）

## インストール

1. GitHub の **Actions** タブ → 最新の「Build APK」→ `KidsHome-apk` をダウンロード
   （または Android Studio でこのフォルダを開いて ▶ 実行）
2. zip を展開した `app-debug.apk` をタブレットへ送ってインストール
   （「提供元不明のアプリ」の許可が必要です）
3. ホームボタンを押して **「キッズホーム」→「常時」** を選ぶ
4. ⚙️ を2秒ながおし → かけ算 →「せってい」でボタンを登録

いつでも最新版：<https://github.com/kiwiman0706-beep/Theta.KidsHome.Hatch/releases/latest/download/KidsHome.apk>（0.12.0 から）

> 署名鍵（`app/kidshome.jks`）を同梱しているので、どこでビルドしたAPKでも上書き更新できます。

## QR コード

おやメニュー →「📷 QR コード で せってい・ほかのタブレットへ」

- **📷 QR コードを読む**：カメラで読むと、スプレッドシートのリンク・Gemini の API キー（`AIza…`）・カレンダーの iCal アドレスを見分けて設定します。スプレッドシート・Gemini・カレンダーの各欄にも「📷 QR」ボタンがあります。
- **📲 アプリのダウンロード QR**：新しいタブレットのカメラで読むと、いつでも最新版の APK が落ちてきます（アップデート欄にも同じボタン）。
- **🔁 この設定を QR で渡す**：スプレッドシート・カレンダー（スイッチで Gemini キーも）を `kidshome:setup?…` の QR にまとめ、新しいタブレットの「📷 QR コードを読む」で読ませます。
- 呼びかけのページも「📱 QR で見せる」でスマホに読ませられます。

## お気に入り動画の登録

**いちばん簡単：** Netflix / Prime Video で作品ページを開く → 「共有」→ **「キッズホームに登録」** → かけ算 → 名前と絵文字を選んで登録。

**手動：** おうちのひとメニュー →「🎬 どうがリンクを追加」に作品URLを貼り付け。
例：`https://www.netflix.com/title/80117470`

URL からサービスを判別して、そのアプリで直接開きます（開けないときはブラウザなどにおまかせ）。

## じしょ・ひゃっかじてん

本棚の「しらべる」→「📖 じしょ」。家の CD-ROM 辞書を 変換した データ（SQLite 1 ファイル）を よみます。データ と 変換スクリプト は 非公開リポジトリ（`dict/README.md`）。
- タブ：あ こくご（デイリーコンサイス）・A えいご・🌍 ひゃっか（エンカルタ）、「🔎 もっと くわしく」で 広辞苑・研究社
- 読み・漢字・英語 で ひく。漢字 は 学年（小1〜6・中学）つき、その子の 学年 まで の「きょう の かんじ」
- リンク で とぶ・⬅️ で もどる・🔊 読みあげ、図・筆順・外字 も 表示
- 辞書 は あとから 足せる：dict フォルダ の `*.sqlite` を ぜんぶ 読む（1 冊 ずつ でも まとめて でも）。SD カード の `Android/data/com.theta.kidshome/files/dict/` に おける
- おやメニュー「📖 じしょ・ひゃっかじてん」：ファイル ごと の 一覧・けす・さがしなおす、ファイル を えらんで 入れる（SD が あれば SD に）、見せる 辞書（はじめ は 医学辞典 も ぜんぶ）

## ガイド役（3D キャラ・きせかえ）

へや の マスコット を 3D キャラ に できます（いき・まばたき、タップで 手をふる・えがお・ジャンプ）。👗 で きせかえ（子どもごと）。

3D は タブレット では かきません。パソコン（または Actions）で 3D を **パラパラ漫画（連番の 絵）** に して おき、アプリ は 絵 を ならべる だけ です（どの 端末 でも 出て、電池 も くわない）。
服・かみ の 色ちがい は、色 を かける ところ の マスク も 作って おいて、アプリ が ぬります。
- 3D → 絵：`guide-renderer/`（[three.js](https://threejs.org/)・[three-vrm](https://github.com/pixiv/three-vrm)、MIT）。`node guide-renderer/render_sprites.js <パック> <出力>`（Node と Playwright）
- アプリ には デフォルト の「ガイドちゃん」（pixiv の VRM サンプル、VRM Public License 1.0：再配布・改変 可、クレジット不要）の 絵 が 入っています（約 1MB）
- 自分の モデル は **非公開リポジトリ の Release（`guide-pack.zip`）** を 読み取り専用トークン で とってくる か、zip を 読みこむ（おやメニュー →「🧸 ガイド役」）。パック の 作りかた は 非公開リポジトリ の README

- **🔁 ループ**：はやさ（BPM、はじめは 96）・はく（2/3/4/6）・しょうせつ（1/2/4/8）を きめて、その ながさ を くりかえす。
  - ⏺ で 1 しょうせつ カウント（3・2・1）してから ろくおん、もう一度 ⏺ で おわり（くりかえしは つづく）。もう一度 ⏺ で かさねどり
  - タイムライン（16 ぶん の マス）に ドラム と けんばん が 見える。ドラム は マス を タップ しても おける・けせる
  - 🔔 メトロノーム、🧲 マスに ぴったり、↩️ さいごに 録った ぶん を けす、🗑️ ぜんぶ けす
  - 音色に 🎶 マリンバ を たした。うちがっき は 大きめ に

**れんしゅう**：曲を選ぶと、次に押す けん が光って、押すまで待ってくれます（片手・1 音ずつ）。上にドレミのならびが出て、いまの音が大きくなります。▶️ でおてほん。

## くるくる思考パッド（内蔵）

くるくる思考パッド（回転盤・回転図形・かさねる・積み木 3D・ホワイトボード ほか）を、そのままアプリの中に入れました（`app/src/main/assets/edupad`）。オフラインで動き、ホームの「🧠 くるくる思考パッド」から開きます。
📷 ほぞん・PNG は「写真」へ、バックアップの書き出しは「ダウンロード」へ保存、共有は Android の共有シート、🖨️ は Android の印刷につながります。左下の 🏠 でホームへ。
くるくる思考パッドを更新したときは、`app/` フォルダを `assets/edupad` に置き換えます（`index.html` の 2 か所の印 `kidshome-bridge.js`／`!window.KidsHome` は残す）。

## スタンプ・シール ライブラリ

![](docs/stamps.png)

写真や画像から シール を作って、ライブラリにためておきます（おえかき のスタンプ、ホームに うかぶ シール などで使う）。

- 作り方：おえかき の 🌟 →「➕」、または おうちのひと →「🌟 スタンプ・シール ライブラリ」→「＋ シールを つくる」
  1. 📷 写真・画像を選ぶ（持っているシールを撮った写真など）
  2. **✨ かたどり**（Gemini が主役だけを切り抜く。写真は Google に送られます）／ **✂️ まわりを けす**（白い紙などの背景の色を消す）／ **⬜ そのまま**
  3. 🤍 白いフチ（シールの形）あり・なし、なまえ を付けて ライブラリへ
- おえかき：スタンプの列に ライブラリのシールが並ぶ（大きさは 3 だん）。🏠 で そのシールを ホームに うかべる
- ホーム：うかべた シールは ふわふわ動き、指で動かせる。タップで大きく・はがす
- 書き出し・読み込み：ZIP（index.json と PNG）。ほかの端末・ほかの機能でも同じ形で使えます
- 市販のシールの写真から作ったものは、家の中だけで使ってください（ZIP を人に配らない）

## もじ れんしゅう（手書きフォントの素材あつめ）

  - **ZIP**：PNG（512px 透過）・SVG・線のデータ（strokes.json、おれん字 てがき と同じ形式）
- 都道府県名の 11 字（茨・媛・岡・熊・埼・鹿・栃・奈・梨・阪・阜）は おれん字 の用紙に無いので、PDF には出ず ZIP にだけ入ります
- 漢字の学年は [learned-kanji](https://www.npmjs.com/package/learned-kanji)（MIT、学年別漢字配当表 平成29年告示）から、用紙の文字の並びは おれん字 てがき から

## くくの ひょう

9×9 のます。

- 「〇のだん」を押すと その段を、うえの すうじ を押すと たての ならびを、順に読み上げます（読んでいる ます が光る）。
- ます を押すと「さざんが く」と読み上げ、右に 式・となえかた・まるの図（3 が 4 こぶん）を大きく出します。
- 🙈 かくす：答えが ★ にかくれ、押すと ひらきます。🎲 もんだい で まだ ひらいていない ます を出題（「さざんが…」まで読む）。もう一度 🙈 で ぜんぶ かくしなおし。
- 🐢 で ゆっくり読み上げ。読み上げは端末の「音声読み上げ」（日本語）を使います。

## たしざん の ひょう

くくの ひょう と おなじ 形（読み上げなし）。「1〜9」と おうようの「11〜20」（11〜20 に 1〜9 を たす）。

せってい →「🗂 アプリの仕分け」の「仕分けガイド」、または「すべてのアプリ」の「仕分け N」（N は未分類の数）。

### 📦 せってい を まとめて うつす
「🔗 つなぐ・うつす」→「📦 せってい を まとめて 書きだす・うつす」
- 💾 ファイル に 書きだす／📂 ファイル から 読みこむ（kidshome-settings.json）
- 🔁 QR で ほか の タブレット へ：なんまい か の QR を じゅんばん に 出す → うけとる がわ は「📷 QR を 読みこむ」で インカメラ に むける だけ（ぜんぶ そろう と 入る）
- 入る もの：こども・タイル・カテゴリー・せいげん・ポイント の きまり・暗証番号・チャット の あいことば・テプラ・きせかえ の せってい など
- 入らない もの：ポイント の 残高・りれき、GitHub トークン、この タブレット が だれ の もの か・ふせん（Gemini キー は スイッチ で えらぶ）

## 🪙 ポイント・ごほうび しへい・💌 チャット

### 🪙 ポイント
ホーム の みだし の「🪙 123」で つうちょう（のこり・きょう もらった 数・りれき・🎁 こうかん）。
- もらえる：もじ 1 字 = 1（1 セット ぜんぶ で +10）、くく・たしざん・そろばん・とけい の せいかい = 1、おみせやさん の おつり せいかい = 1、うごかして ゴール = ⭐ の 数、にほん パズル = 5（ぜんぶ 20）、パズル = 3、タイピング = 3
- おなじ 字・おなじ もんだい は 1 日 1 かい だけ。1 日 の 上限（30／50／100／なし）は 親モード で
- つかう：きせかえ 1 こ = 10、ごほうび スタンプ = 親 が きめた ねだん（10／20／50）
- まえ の 🎟 チケット は のこって いた 数 × 10 ポイント に かわります（はじめ に +30）
- つうちょう・きせかえ・こうかん の 画面 に「いま 🪙 ○」と「✏️ 字 を かいて ためる」「➕ たしざん」「✖️ くく」ボタン（たりない とき も）

### 💴 ごほうび しへい（QR）
親モード「🪙 ポイント・ごほうび しへい」で 1／5／10／50／100 ポイント の しへい を A4 に 印刷（または 共有）。
子ども は「🪙」→「📷 ごほうび しへい を よみこむ」で インカメラ に かざす →「🔑 おうちのひと」で **暗証番号**（4〜8 けた、親モード で きめる）→ もらえる。
- 1 まい 1 かい（つかった ばんごう は タブレット が おぼえる）。暗証番号 が ない あいだ は むずかしい かけ算
- 親モード の 入り口 も 暗証番号 に できる（スイッチ）

### 🧩 スタンプ を きりわける・🎁 ごほうび スタンプ
親モード「🌟 スタンプ・シール ライブラリ」→「🧩 1 まい の 絵 を きりわける」：イラスト が たくさん ならんだ 画像（白 など 1 色 の 背景）を えらぶと、1 こ ずつ に きって 背景 を けし、しろい ふち を つけます。えらんで「ライブラリ へ」。
- 「ふつう」は すぐ つかえる。「🎁 🪙20」など に する と、子ども が ポイント で こうかん する まで つかえない（ライブラリ の 下 の ボタン で かえられる）
- こうかん した スタンプ は おえかき・ホーム に うかべる・チャット で つかえる
- 🖍 ぬりえ：おえかき の「🖍 ぬりえ」で えらぶ（りんご・さかな・おうち・ねこ・おはな・くるま・ちょうちょ・ロケット・アイス・くま。アプリ で 線 を ひいた もの）。線 は いちばん うえ に かさなる ので、ぬって も きえない。🪣 バケツ で かこまれた ところ を 1 かい で ぬれる
  - 「➕ がぞう から つくる」：ぬりえ の 画像 や 線画 を えらぶ と、黒 い 線 だけ に して 足せる（ながおし で けす）
  - あとで 素材 を 足す とき は `app/src/main/assets/nurie/` に PNG（黒 い 線・白 か すけた 背景）を 入れる と 内蔵 の あと に ならぶ
- 🎨 おえかき：「✏️ ペン だけ」は ながおし で きりかえ（うっかり かわらない）。ゆび で スタンプ を おす とき は ながく おす ほど 大きく（おして いる あいだ ふくらむ、みじかく はなす と 小さい）。ペン モード では 筆圧 で 大きさ
- 🎨 おえかき の 🌟（スタンプ）：じぶん の スタンプ が さいしょ に 大きく ならぶ。まだ こうかん して いない ごほうび スタンプ は 🔒 で 見えて、おす と こうかん 画面（「🎁 もっと」も）
- 🎨 おえかき の「🌟 スタンプ に する」：じぶん で かいた 絵 の まわり を けして スタンプ に（すぐ つかえる）
- 自作・フリー素材 を つかって ください（キャラクター もの は 入れない）

### 💌 かぞく の チャット（ntfy）
親モード「💌 かぞく の チャット」で「🎲 あたらしく つくる」→「きめる」。ほか の タブレット には「🔗 QR」を 見せて「📷 QR を よみこむ」（または 手 で 入力）。
- ホーム の「💌」で、スタンプ と きまった ことば（おはよう・だいすき・あそぼう！ など）を おくりあう。とどく と 上 に「💌 ○○ から」
- 中身 は あいことば から つくった かぎ で 暗号化（AES-GCM）して ntfy.sh に おくる ので、サーバー から は 読めない。とどいて 3 時間 いない に アプリ を ひらく と 受けとれる
- NAS に ntfy を 立てたら「ntfy サーバー」を その アドレス に かえる だけ

## 👪 かけいず・たんじょうび

カレンダー の「👪 かけいず」から。おうちのひと が ✏️（かくにん つき）で 家族 を 入れる：なまえ・よびかた・かお写真・たんじょうび（年 は なくても）・おとうさん／おかあさん・けっこん して いる 人・この 子 本人（⭐）。ともだち は たんじょうび だけ。
- 人 から 人 へ ゆび で ひっぱる と「わたし から みる と ゆみ は『おばさん』（わたし の おとうさん の いもうと）」「ゆみ から みる と わたし は『めい』」を 出して 読みあげ
- タップ で たんじょうび・あと なんにち・なんさい・うまれ年 の 干支
- カレンダー に 🎂、こんげつ の たんじょうび（なんさい に なるか）、けいじばん に「きょう は ○○ の たんじょうび！」
- 写真 と データ は アプリ の 中（filesDir/kin）

## 🔢 さんすう の どうぐ

- **🗾 にっぽん パズル**：都道府県 の ピース を 地図 に はめる（ぜんぶ／地方 ごと、🏷 なまえ の ヒント、ゆび 2 本 で 大きく・小さく、1 本 で うごかす、➕➖🔄）。ハマると 名前・けんちょう・名物（えもじ）・とくちょう の カード。はめた 県 を タップ でも もう いちど 見られる。カード の「📷 しゃしん を いれる」で あそび に いった ときの 写真 を 県 ごと に 入れられ、「📷 おもいで」で 行った 県 の 地図（タップ で 写真）。写真 は アプリ の 中 に 小さく して コピー（アンインストール で 消える）。地図 は Natural Earth（パブリックドメイン、`tools/build_japan_map.py`）。
- **🧮 そろばん**：玉 を タップ で はじく（上 5・下 1、定位点 つき）。🧹 ごはさん、👀 かず を かくす、🎲 おく／＋／−（1〜3 けた）。
- **🔢 ひっさん でんたく**：でんたく で 計算 すると、よこ に ひっさん（くりあがり・くりさがり・かけ算 の だん・わり算 の 商 と あまり）。👣 ひとつずつ で 1 だん ずつ 出せる。
- **もじ れんしゅう** の よこ に、おてほん の 書き順 アニメ（番号つき）・かくすう・おん／くん・ことば。タブレット に こくご 辞書 が あれば いみ も。
  データ：KanjiVG（書き順）・KANJIDIC2／JMdict（読み・ことば）、どちらも CC BY-SA（`tools/build_kanji_info.py`、`assets/licenses/kanji-data.txt`）。

## 📱 この タブレット・かべがみ

1 人 1 台 なので、ホーム には 子ども の きりかえ を 出しません。おやメニュー「📱 この タブレット」で だれ の タブレット か を えらび、「🖼 かべがみ・ロック画面 を そろえる」で テーマ の 絵（ロック画面 には なまえ）に できます。

アプリ の 仕分け では「🗑 アンインストール」も えらべます（もとから 入っている アプリ は アプリ情報 から 無効 に）。

がっき の ドラム・せかい の 音 は GM 音源（FluidR3_GM、MIT）から 書き出した 本物 の 音 です（`tools/render_gm_drums.py`）。

## 📱 おやモード（おや の スマホ から そうさ）

おや の スマホ にも おなじ APK を 入れて、タブレット と つなぎます。

1. タブレット：せってい →「📣 呼びかけ」をオン →「📱 おや の スマホ と つなぐ」で QR を出す
2. スマホ：キッズホームを開いて ⚙ →「📱 この スマホ を おやモード に」→「📷 タブレット の QR を 読んで つなぐ」
3. スマホ が タブレットごと の カード に なり、ここから：
   - めっせーじ（呼びかけ）、どうがロック（15〜120分）・かいじょ
   - 曲 を 送る（ドレミ書き または けんばん で ひいて きろく）
   - よる くらく・ガイド役・じどうアップデート・辞書のレベル
   - タブレット の ようす（バッテリー・バージョン・ロック中か・入っている曲）

つないだ とき に 合いことば（鍵）を 交換し、めいれい には しるし（HMAC）を つけるので、
呼びかけ の アドレス を 知っているだけ の 人 は 設定を かえられません（10分 より 古い めいれい も 無視）。
つなぐ QR は 自分 の スマホ に だけ 見せてください。

**🧪 ベータ テスト**：おやモード の 画面 下 の「アプリ を せいげん なし で ひらく」で、スマホ で キッズホーム を そのまま ためせます（どうがロック・夜 の くらさ・おうちのひと かくにん・辞書 の レベル・カテゴリー の 見せる 子 は はずれる）。画面 下 の むらさき の ボタン で おやモード に もどる。

タブレット は 何台 でも つなげます（子ども ごと に カード、✏️ で よびな を かえる）。2 台 いじょう つなぐ と「👨‍👩‍👧‍👧 みんな に」で メッセージ・どうがロック・曲 を まとめて 送れます。

## 制限について（大事）

このアプリは「ホームに出すものを絞る」タイプの制限です。Android の仕組み上、以下は防げません。

- 通知バーからの設定変更、最近使ったアプリ一覧からの切り替え
- 動画アプリの中で別の作品を探すこと

しっかり縛りたい場合は、あわせて次を使うのがおすすめです。

- **Google ファミリーリンク**：アプリのインストール制限・利用時間
- **Netflix のキッズプロフィール** / **Prime Video のキッズプロフィール**
- Android の **アプリ固定（画面の固定）**

## 新しい版の出し方（自動更新）

1. `app/build.gradle.kts` の `versionCode` と `versionName` を上げる
2. GitHub の Actions →「Release APK」→ Run workflow → 版（例 `v0.2.0`）を入れて実行
3. Release に `KidsHome-<版>.apk` と `SHA256SUMS.txt` が載り、タブレットが自動で見つけます
