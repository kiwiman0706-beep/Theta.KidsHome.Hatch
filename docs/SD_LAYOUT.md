# SD カード の 入れかた（キッズホーム）

動画・音楽・おはなし（音声の本）・辞書 を microSD に 入れて、キッズホーム で 見る ための きまり です。
パソコン（カードリーダー）で SD に コピー する 作業 を、そのまま 人 や AI に 渡せる ように まとめています。

## 1. ぜんたい の 形

```
SD カード（ルート）
├─ KidsHome/
│  ├─ どうが/                         ← 🎬 ビデオ
│  │  ├─ アンパンマン/                ← 左の 一覧 に 出る「シリーズ」
│  │  │  ├─ folder.jpg                ← 左の 一覧 の アイコン（なくても よい）
│  │  │  ├─ 01 アンパンマン と ばいきんまん.mp4
│  │  │  ├─ 02 ….mp4
│  │  │  └─ シーズン2/                ← もう 1 段 わけても よい（右に 見出し が 出る）
│  │  │     └─ 01 ….mp4
│  │  └─ しぜん の ずかん/
│  │     └─ ….mp4
│  ├─ おんがく/                       ← 🎵 おんがく
│  │  ├─ ジブリ/                      ← 左の 一覧（グループ・歌手 など）
│  │  │  ├─ folder.jpg                ← 左の 一覧 の アイコン
│  │  │  ├─ となりのトトロ/           ← 右の 1 まい（アルバム）
│  │  │  │  ├─ cover.jpg              ← アルバム の ジャケット（埋め込み より 優先）
│  │  │  │  ├─ 01 さんぽ.mp3
│  │  │  │  └─ 02 となりのトトロ.mp3
│  │  │  └─ 魔女の宅急便/
│  │  └─ どうよう/
│  │     └─ どうよう ベスト/
│  │        └─ 01 ….m4a
│  └─ おはなし/                       ← 🎧 おはなし（オーディオブック・朗読）
│     ├─ 日本の むかしばなし/         ← 左の 一覧（シリーズ）
│     │  ├─ folder.png                ← 左の 一覧 の アイコン
│     │  ├─ ももたろう/               ← 右の 1 さつ
│     │  │  ├─ cover.jpg              ← 本 の 表紙
│     │  │  ├─ 01 ….mp3
│     │  │  └─ 02 ….mp3
│     │  └─ かぐやひめ.m4b            ← 1 ファイル の 本 でも よい
│     └─ グリム どうわ/
└─ Android/data/com.theta.kidshome/files/dict/   ← 📚 じしょ（ここ だけ 場所 が ちがう。くわしく は 3.）
   ├─ kokugo.sqlite                   ← 1 冊（なかま）ごと に 1 ファイル。何こ でも
   ├─ hyakka.sqlite
   └─ hyakka.sqlite-media/            ← 大きい 図・動画 を DB の 外 に 出した とき だけ
```

- 画面：**左 に「シリーズ（KidsHome/どうが・おんがく・おはなし の すぐ 下 の フォルダ）」、右 に サムネイル**。
- フォルダ名・ファイル名 が そのまま 画面 に 出ます。**子ども が 読める ことば（ひらがな 多め）** に して ください。
- 階層 は「種類 / シリーズ / （アルバム・本 / ）ファイル」まで。それ より 深く しても 動きます が、右 の 見出し が ふえる だけ です。

## 2. ファイル の きまり

| | きまり |
| --- | --- |
| 並び順 | ファイル名 の 文字コード 順。**先頭 に 2〜3 けた の 番号**（`01 `、`02 `、… `10 `）。番号 は 画面 では 消えます（`01 `・`01_`・`01.`・`01-` どれでも） |
| 番号 の けた | 同じ フォルダ の 中 は けた を そろえる（`1`,`2`,`10` だと `10` が `2` より 先 に なる） |
| 使えない 文字 | `\ / : * ? " < > |`（SD の exFAT/FAT32 で 使えない）。名前 は 100 文字 くらい まで |
| 隠す | 見せたく ない フォルダ には 空 の `.nomedia` ファイル を 置く（Android が その フォルダ を 読まなく なる）。おやメニュー「📼 端末の動画・音楽・おはなし」→「フォルダごとに 見せる・かくす」でも 隠せる（シリーズ単位 でも） |
| SD の 形式 | exFAT（64GB 以上 の カード の 標準）で OK |
| アイコン | フォルダ の 中 に `folder.png`／`folder.jpg`、なければ `icon.*`、`cover.*`（png・jpg・jpeg・webp、大文字 小文字 は どちら でも）。正方形 で 512×512 くらい が きれい。シリーズ の フォルダ に 置く と 左 の 一覧、アルバム・本 の フォルダ に 置く と 右 の ジャケット に なる。ない とき は 最初 の 動画 の 1 コマ／埋め込み ジャケット |

### 動画

- **MP4（H.264 映像 ＋ AAC 音声）** が いちばん 確実。1080p まで。
- MKV・WebM も 再生 できる が、サムネイル が 出ない こと が あり ます。
- 1 本 ずつ の サムネイル は 動画 の 1 コマ を 自動 で 使う。シリーズ の アイコン だけ `folder.jpg` で 好き な 絵 に できる。
- 変換 の 例（ffmpeg）：

```bash
ffmpeg -i 元.mkv -c:v libx264 -crf 22 -preset medium -vf "scale='min(1920,iw)':-2" -c:a aac -b:a 160k -movflags +faststart "01 タイトル.mp4"
```

### 音楽・おはなし

- **MP3 か M4A（AAC）**。おはなし は 1 冊 1 ファイル の **M4B** でも よい。
- ジャケット は アルバム の フォルダ に **`cover.jpg` を 置く** か、**ファイル に 埋め込む**（両方 あれば `cover.jpg`）。
  `cover.jpg` を つかう には、おやメニュー で「写真（画像）の 許可」も 出して ください（下 の 4.）。

```bash
# MP3 に ジャケット を 埋め込む
ffmpeg -i "01 さんぽ.mp3" -i cover.jpg -map 0:a -map 1 -c copy -id3v2_version 3 -metadata:s:v comment="Cover (front)" out.mp3
# M4A
ffmpeg -i "01 さんぽ.m4a" -i cover.jpg -map 0:a -map 1 -c copy -disposition:v attached_pic out.m4a
```

- 曲名 は タグ の「タイトル」→ なければ ファイル名。アルバム は タグ の「アルバム」→ なければ フォルダ名。
  **タグ を 入れない なら、フォルダ名 ＝ アルバム名、ファイル名 ＝ 曲名** に して ください（いちばん 確実）。
- タグ を 入れる なら、同じ アルバム の 曲 は アルバム名 を そろえる（ずれる と 別 の 1 まい に なる）。トラック番号 も 入れる と その 順 に なる。
- `おはなし/` の 下 に ある もの は ぜんぶ「おはなし」に なる（続き から 再生・速さ 🐢🙂🐇・30 秒 とばし）。
- 30 秒 より 短い 音 は 効果音 と みなして 出しません（おはなし は 出す）。

## 3. 辞書（じしょ・ひゃっかじてん）

### 置き場所
- **`SD/Android/data/com.theta.kidshome/files/dict/`**（アプリ専用 の フォルダ）。本体 の `…/files/dict/` も 読む（SD が 先）。
  - フォルダ が なければ、キッズホーム を 一度 ひらいて おやメニュー「📖 じしょ・ひゃっかじてん」を 見る と できます。パソコン で 先 に 作って も かまいません（名前 を 正確 に）。
  - **キッズホーム を アンインストール する と この フォルダ は 消えます**。元 の `.sqlite` は パソコン（NAS）に 残して おいて ください（アップデート では 消えません）。
  - 動画・音楽 と ちがって、辞書 は ふつう の フォルダ（`KidsHome/` の 下）では 読めません（Android の 制限）。
- パソコン が なくても、`.sqlite` を タブレット の どこか（ダウンロード など）に 置いて、おやメニュー「📖 じしょ・ひゃっかじてん」→「ファイル を えらんで 入れる」で コピー できます（SD が あれば SD へ、同じ 名前 は 入れかえ）。
- 入れた あと は おやメニュー「📖 じしょ・ひゃっかじてん」の「さがしなおす」で 読み直し。ファイル の 一覧（SD／本体・大きさ）と けす ボタン も そこ に あります。

### ファイル の 中身
- 1 ファイル = SQLite の DB 1 つ。中 に 1 冊 でも 何冊 でも 入れられる。**1 冊（なかま）ごと に 1 ファイル** に しておく と、あと から 足す・入れかえる の が かんたん。
- アプリ は フォルダ に ある `*.sqlite` を ぜんぶ 読んで、本 ごと に たな に ならべる。ファイル名 は 自由（英数字 が ぶなん）。
- 表（テーブル）：
  | 表 | 中身 |
  | --- | --- |
  | `dict` | 本 1 冊 ＝ 1 行：`code`（みじかい 英字）・`title`（書名）・`tab`・`level`・`entries`（項目数） |
  | `entry` | 項目：`heading`（見出し）・`reading`（よみ）・`kanji`・`grade`（学年。漢字 に だけ）・`body`（本文。Markdown の 一部、`[[リンク]]`・`![[図.png]]`） |
  | `media` | 図・音（DB の 中 に 入れた もの） |
  | `entry_fts` | 本文 の 全文検索（あれば。作る とき `--fts`） |
- `tab`（たな）：`kokugo` こくご／`eigo` えいご／`hyakka` ひゃっか／`karada` からだ／`other` ほか
- `level`：1 いつも 出る／2「もっと くわしく」で 出る／3 おや の 設定 で 出す（いま は はじめ から ぜんぶ 出る 設定）
- `code` が `kokugo` で `grade` つき の 漢字 が ある 辞書 は、「きょう の かんじ」と もじ れんしゅう の「いみ」にも つかわれる。

### 作りかた
- 元 の Vault（Markdown の フォルダ）から、非公開リポジトリ の `tools/build_dict_db.py` で 作る。くわしい 手順・オプション・どの 辞書 を どの タブ に する か は 非公開リポジトリ の `dict/README.md`。
- 市販 の 辞書 の 中身 なので、家 の 中 で だけ。公開 リポジトリ・APK には 入れない。

## 4. コピー した あと

1. SD を タブレット に さす（入れっぱなし で OK）。
2. 数分 で Android が 新しい ファイル を 見つけます。出て こない とき は タブレット を 再起動。
3. おやメニュー「📼 端末の動画・音楽・おはなし」で「動画と音楽へのアクセスを許可」。
   いっしょ に 写真（画像）の 許可 も 聞かれる ので「許可」（`folder.jpg`・`cover.jpg` を 読む ため。前 から 使って いる タブレット は「🖼 フォルダ の アイコン も 読む」ボタン で）。
4. 見せたく ない フォルダ（カメラ・スクショ など）は おやメニュー「📼 端末の動画・音楽・おはなし」→「フォルダごとに 見せる・かくす」。

## 6. 今後 の 予定（おぼえがき）

- Tailscale の VPN モード で NAS に いつも つながる 前提 の アイデア は `docs/ROADMAP.md`「Tailscale で NAS に いつも つながったら」。

- **NAS と 同期**：Wi-Fi に つながって いる とき、Tailscale 経由 で 家 の NAS（Synology）と SD の `KidsHome/` を 同期 する。
  - 最終的 に は NAS 側 が 正（NAS に 入れれば タブレット に 入る）。
  - この 文書 の フォルダ構成 を そのまま NAS の 共有フォルダ にも 使う 前提（NAS 側 も `KidsHome/どうが・おんがく・おはなし`）。
  - 辞書（`Android/data/com.theta.kidshome/files/dict/`）も 同期 対象 に する か は 実装時 に 決める。
  - モバイル回線・車 の 中 では 同期 しない（Wi-Fi のみ・充電中 のみ など）。
