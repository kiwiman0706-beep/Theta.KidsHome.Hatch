## 🌏 せかい ちず パズル（世界地図版）

## 🌱 やさい・くだもの の そだちかた（アニメ）
- [ ] たね を 見せる → まく → 芽 → そだつ → とれる まで の アニメ
- [ ] 土 の 中 に できる（じゃがいも・にんじん・かぶ・ごぼう・だいこん・さつまいも）か、上 に できる（トマト・ブロッコリー・かぼちゃ・ピーマン・なす・きゅうり）か
- [ ] 切った ところ（断面）：トマト・たまねぎ・おくら・キャベツ・ピーマン …
- [ ] まく 季節・とれる 季節（しゅん）も 出す

## 💧 うく・しずむ（アニメ）
- [ ] 水 に そっと 入れる と うく か しずむ か を 当てて から アニメ で 見る
  - うく：きゅうり・りんご・はっぱ・えんぴつ・かぼちゃ
  - しずむ：1えんだま…（※1円玉 は そっと のせる と うく ことも ある）・たまご・じしゃく・コップ・さつまいも
- [ ] なぜ？（おもさ と 大きさ ＝ 密度 を やさしく）

## 🔬 じっけん（アニメ）
- [ ] 水 を 火 に かける：小さな あわ が つく → 大きな あわ → ふっとう → ゆげ。温度計 つき
- [ ] ほか：氷 が とける、塩 が とける、色水 の まぜかた、影 の 長さ と 時間 など
