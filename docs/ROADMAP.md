## 作りかた の きまり（内容 が ふえて きた とき）
- 内容（ことば・説明・クイズ・名物 など）は コード に 書かず、テーマ ごと の 別ファイル に する
  - `app/src/main/assets/content/<テーマ>.json`（例：`seasons.json`・`counters.json`・`world.json`・`vegetables.json`・`floatsink.json`・`odd-one-out.json`）
  - アプリ は ファイル を 読む だけ。文言 を 直す とき は その ファイル だけ 直せば いい
  - あとで SD（`KidsHome/content/`）に 同じ 名前 の ファイル を 置けば そちら を 優先、も できる 形 に
- いま コード に 入って いる 都道府県 の 説明（`data/Japan.kt`）も、世界地図 を 作る とき に `content/japan.json` へ うつす
- この リスト も 長く なったら `docs/roadmap/<テーマ>.md` に わける

## 🔐 Tailscale で NAS に いつも つながったら（提案）

前提：子ども の タブレット・おや の スマホ が Tailscale の VPN モード（常時接続）で 家 の NAS（Synology）に つながる。
車 の 中（スマホ の テザリング など）でも NAS に とどく が、通信量 が かかる ので「Wi-Fi の とき だけ」「充電中 だけ」を えらべる よう に する。

### いちばん 効く もの
- [ ] **SD と NAS の 同期**：NAS の `KidsHome/`（どうが・おんがく・おはなし・じしょ）を Wi-Fi＋充電中 に SD へ 自動 で コピー／けす。NAS に 入れれば 次 の 日 には タブレット に 入って いる。車 では SD の もの を 見る ので 通信 なし
  - NAS 側 は WebDAV（Synology の WebDAV Server）か SMB。差分 だけ、とちゅう で 切れても つづき から
  - 辞書 の `.sqlite` も 同じ しくみ で `Android/data/…/dict/` へ（アンインストール で 消えて も NAS から もどる）
- [ ] **NAS から 直接 再生（ストリーミング）**：SD に 入れて いない 動画・音楽 も、家 や Wi-Fi の ある ところ では NAS から そのまま 見る（ExoPlayer で WebDAV／HTTP）。左 の 一覧 に「🏠 おうち の NAS」の たな
- [ ] **バックアップ**：おえかき・もじ（フォント 素材）・ワープロ・ろくおん・都道府県 の 写真・設定 を 毎晩 NAS へ。タブレット を 買いかえて も そのまま もどせる
- [ ] **呼びかけ・おやモード を NAS 経由 に**：いま は 公開 の ntfy.sh を 中継 に して いる → NAS に ntfy を 立てて（Docker）家族 だけ の 中継 に。外 に 出る 通信 が なくなる

### あると たのしい もの
- [ ] **Synology Photos と つなぐ**：けいじばん・イーゼル に 家族 の 写真 を スライド。にっぽん パズル の「おもいで」に、写真 の 位置情報 から 県 を 自動 で わりふり
- [ ] **DS Chat（Synology Chat）**：前 に 話した 家族 チャット。Tailscale なら QuickConnect なし で 直接（スタンプ・ボイス メッセージ）
- [ ] **内容ファイル を NAS で 編集**：`content/*.json`（季節・かぞえかた・クイズ・都道府県 の 説明 …）・ピアノ の 曲・スタンプ を NAS の フォルダ に 置いて、PC で 直す と タブレット に 反映
- [ ] **ようす の 記録**：何 を どの くらい 使ったか・バッテリー を NAS に ためて、おや の スマホ で グラフ（スクリーンタイム の かわり）
- [ ] **アップデート・ガイド役 の パック を NAS から**：GitHub に とり に いかず、家 の 中 で 配る（非公開 の もの も トークン なし で）
- [ ] **カレンダー**：Synology Calendar（CalDAV）を そのまま けいじばん に
- [ ] **ラジオ**：Audio Station の プレイリスト・録音 した ラジオ番組 を「ラジオ」に

### 気 を つける こと
- 子ども が VPN を 切れない よう に：Android の「常時接続 VPN」＋「VPN 以外 の 接続 を ブロック」は、NAS に とどかない とき ネット が ぜんぶ 止まる ので、ブロック は オフ を すすめる
- ファミリーリンク の 端末 は Tailscale アプリ の インストール・VPN の 設定 に おや の 許可 が いる
- NAS の アカウント は 子ども 用 に 読み取り だけ の もの を 作る（けせない・書きかえられない）
- 車 で の 通信量：ストリーミング は Wi-Fi のみ を 初期値 に
